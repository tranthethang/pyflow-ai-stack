# S3 Storage Service

**S3Service** provides an asynchronous interface for interacting with S3-compatible storage services like AWS S3 or MinIO using `aioboto3`.

## Initialization

Initialize the service with an `S3Config` object:

```python
from pyflow_ai_stack.services.configs import S3Config
from pyflow_ai_stack.services.s3_service import S3Service

config = S3Config(
    access_key_id="your_access_key",
    secret_access_key="your_secret_key",
    region="us-east-1",
    bucket_name="my-bucket",
    endpoint_url="http://minio:9000"  # For local development with MinIO
)
s3_service = S3Service(config)
```

## Methods

### `upload_file`

Uploads content (string or bytes) to the S3 bucket.

- **`content`** (`Any`): The data to be uploaded (string or bytes).
- **`s3_key`** (`str`): The key (path) under which the file should be stored.
- **`content_type`** (`str`, default: `"text/plain"`): The MIME type of the content.

**Returns**: `str` (The S3 URI of the uploaded file, e.g., `s3://bucket/key`).

### `get_file`

Downloads content from the S3 bucket.

- **`s3_key`** (`str`): The key (path) of the file to retrieve.

**Returns**: `bytes` (The content of the file).

### `ping`

Checks if the S3 bucket is accessible by calling `head_bucket`.

**Returns**: `bool` (`True` if the bucket is accessible, `False` otherwise).

## Custom Endpoint Support

You can use `S3Service` with local storage or alternative S3-compatible providers by specifying the `endpoint_url` in the configuration. For MinIO, it's common to also set `with_path_style=True`.

## Example: Storing and Retrieving Content

```python
s3_path = "reports/daily_report.txt"
content = "This is the content of the report."

# 1. Upload
s3_uri = await s3_service.upload_file(content, s3_path)
print(f"Uploaded to: {s3_uri}")

# 2. Download
downloaded_bytes = await s3_service.get_file(s3_path)
print(f"Downloaded content: {downloaded_bytes.decode('utf-8')}")
```
